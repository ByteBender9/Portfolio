## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ByteBender9/portfolio.git
```

### Navigate into the project

```bash
cd portfolio
```

### Run locally

Open `index.html` directly in your browser, or use **Live Server** in VS Code.
